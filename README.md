This repository contains a selection of data science projects I completed over the summer.

* **shelf_track.py** : This is a program to handle book inventory, using relational databases.
* **task_manager.py** : A program to help a small business manage tasks assigned to each team member.
* **automobiles.ipynb** : I completed an EDA report after cleaning and exploring a dataset.
* **titanic.ipynb** : I completed an EDA report on the titanic dataset containing appropriate visualisations.
* **Linear_Regression_Ames.ipynb** : Performed EDA to gain insight into the dataset and used a
multiple linear regression model to uncover underlying relationships between variables.
* **telco_customer_churn.ipynb** : After preprocessing the data, I applied machine learning models such as logistic regression and random forests to help forecast customer churn. 
* **neural_network_task.ipynb** : I created a program that helps generate slogans based on industry, and predict the industry based on a given slogan.
